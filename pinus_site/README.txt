PINUS — site da apresentação
================================

Abra o arquivo index.html no navegador.

O site foi montado com HTML, CSS e JavaScript puro e usa as imagens dos slides enviados na pasta assets/.

Para publicar:
1. Envie a pasta inteira para um serviço de hospedagem estática (por exemplo, GitHub Pages, Netlify ou Vercel).
2. Mantenha a pasta assets junto do index.html.

Arquivos:
- index.html
- assets/slide-1.png ... slide-12.png
